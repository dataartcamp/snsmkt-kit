# 채널별 SNS 카피라이터

같은 원문/주제를 채널 규격에 맞게 재포장한다. 규격은 채널마다 다르되 목소리는 같아야 하고,
그 목소리를 고정하는 것이 `expert-voice.md`다.

## 입력

| 파라미터 | 필수 | 설명 |
|---|---|---|
| `원문 또는 주제` | 필수 | 원문(블로그 글·강의 노트·상담 메모 등, 길이 무관) 또는 주제 한 줄 |
| `expert-voice` | 선택 | `expert-voice.md` 경로 또는 본문 전체 |
| `채널` | 선택 | `threads` \| `linkedin` \| `통합`(기본값) |

채널 이름이 하나만 나오면 그 채널만 생성한다 — "Threads 카피 뽑아줘"처럼 "만"이 붙지 않아도
같다. 어느 채널도 언급되지 않았을 때만 `통합`으로 두 채널을 만든다.

## expert-voice 확인

**있으면** — 경로·본문·앞선 대화 어디서든 찾으면 읽고 곧바로 생성으로 넘어간다. 다시 묻지 않는다.

**없으면** — 두 갈래를 제시하고 사용자가 고르게 한다:

> "브랜드보이스 기준 문서(`expert-voice.md`)가 아직 없네요.
> ① **먼저 기준 문서 만들기** (권장) — 몇 가지 질문에 답하면 파일이 나오고, 이후 카피가 같은
>    목소리로 나옵니다.
> ② **이대로 카피 뽑기** — 지금 바로 만들어 드립니다. 말투·CTA가 다음번과 달라질 수 있습니다.
> 어느 쪽으로 할까요?"

- ① → `expert-voice-builder`로 문서를 만든 뒤 **원래 요청한 카피까지 이어서 완성한다.**
- ② → 아래 "없을 때" 규칙을 적용해 곧바로 생성한다.

## 공통 규칙

| 적용 시점 | 규칙 |
|---|---|
| **항상** | 훅은 숫자형·대비형·질문형·경험담형 중 하나로 쓴다 |
| | 금지: "혁신적인"·"획기적인"·"놀라운" 같은 과장어, 광고 티 나는 문장 |
| | CTA는 광고 티 없이 자연스러운 행동유도로 쓴다 |
| **expert-voice 있을 때** | 말투·타겟·개인 금지어를 그대로 유지한다 |
| | CTA는 expert-voice의 CTA 섹션에서 골라 주제에 맞게 다듬는다 |
| | 해시태그에 expert-voice의 전문 분야를 반영한다 |
| **없을 때** | CTA는 주제에 맞는 일반 참여 유도로("댓글로 알려주세요", "저장해두세요") |
| | 해시태그는 원문·주제에서 뽑는다 |
| | 톤은 과장 없는 평이한 존댓말을 기본값으로 한다 |
| | 원문에 없는 경력·수치를 지어내지 않는다 |

## 출력 파일

| 채널 | 생성 파일 |
|---|---|
| `threads` | `threads-copy.md` |
| `linkedin` | `linkedin-copy.md` |
| `통합` | 위 두 파일을 각각 생성 — 한 파일로 합치지 않는다 |

원문/주제를 입력받은 위치(또는 사용자가 지정한 폴더)에 저장한다. 같은 이름의 파일이 있으면
덮어쓰기 전에 확인한다.

## Threads — `threads-copy.md`

- 3버전, 각 공백 포함 500자 이내 — 넘으면 다시 세어 줄이고 재출력
- 제목에 글자수를 괄호로 표기
- 버전 1 훅형(첫 문장으로 시선을 끈다) / 버전 2 경험담형(짧은 사례 중심) / 버전 3 질문형(댓글 유도)
- 각 버전 마지막 줄에 CTA 1줄
- 해시태그 2~5개, 한국어 위주

아래 형식으로 파일을 쓴다:

```markdown
# Threads 카피 — {주제 한 줄 요약}

## 사전 준비
- 브랜드보이스 기준 문서: `{경로 또는 "본문으로 전달받음"}`
- 말투·타겟·CTA·금지어를 이 문서 기준으로 썼습니다. 다시 손볼 때도 이 기준을 벗어나지 마세요.

## 사용법
1. 마음에 드는 버전을 그대로 복사하세요.
2. 글자수를 눈으로 한 번 더 확인하세요 (버전마다 괄호로 표기돼 있습니다).
3. Threads 게시 화면에 붙여넣으세요.
4. CTA 문구는 상황에 맞게 바꿔도 됩니다.

## 카피

### 버전 1 — 훅형 (000자)
{카피 본문}
{CTA 1줄}

### 버전 2 — 경험담형 (000자)
{카피 본문}
{CTA 1줄}

### 버전 3 — 질문형 (000자)
{카피 본문}
{CTA 1줄}

## 해시태그
#태그1 #태그2 #태그3
```

`expert-voice` 없이 만들었으면 "사전 준비"의 두 줄만 아래로 바꿔 쓴다:

```markdown
- 브랜드보이스 기준 문서: **없음** — 채널 규격만으로 썼습니다.
- 말투·CTA가 다음에 뽑는 카피와 달라질 수 있습니다. 목소리를 고정하려면
  `expert-voice-builder`로 기준 문서를 만든 뒤 다시 뽑으세요.
```

## LinkedIn — `linkedin-copy.md`

- 1개 버전, 1,300~1,900자, 전문가 1인칭 톤
- 첫 3줄 안에 훅 배치 — '더 보기'로 접히기 전에 핵심이 보여야 한다
- 마지막에 참여 유도 CTA 1줄
- 해시태그 3~5개

아래 형식으로 파일을 쓴다:

```markdown
# LinkedIn 카피 — {주제 한 줄 요약}

## 사전 준비
- 브랜드보이스 기준 문서: `{경로 또는 "본문으로 전달받음"}`
- 말투·타겟·CTA·금지어를 이 문서 기준으로 썼습니다. 다시 손볼 때도 이 기준을 벗어나지 마세요.

## 사용법
1. 아래 카피를 그대로 복사하세요.
2. 글자수를 눈으로 한 번 더 확인하세요 (제목 옆 괄호).
3. LinkedIn 게시 화면에 붙여넣으세요.
4. CTA 문구는 상황에 맞게 바꿔도 됩니다.

## 카피 (0,000자)
{첫 3줄에 훅}

{맥락 → 인사이트 → 제안}

{참여 유도 CTA 1줄}

## 해시태그
#태그1 #태그2 #태그3
```

`expert-voice` 없이 만들었으면 "사전 준비"의 두 줄만 아래로 바꿔 쓴다:

```markdown
- 브랜드보이스 기준 문서: **없음** — 채널 규격만으로 썼습니다.
- 말투·CTA가 다음에 뽑는 카피와 달라질 수 있습니다. 목소리를 고정하려면
  `expert-voice-builder`로 기준 문서를 만든 뒤 다시 뽑으세요.
```

## 관련 스킬

- **`expert-voice-builder`** — 브랜드보이스 기준 문서(`expert-voice.md`)를 인터뷰로 만드는
  스킬. 이 스킬에 줄 `expert-voice`가 아직 없을 때 쓴다.
