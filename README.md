# SNS 마케팅 실습키트

내 전문성을 SNS 콘텐츠로 바꿔주는 AI 스킬 두 개가 들어 있습니다.

| 스킬 | 하는 일 |
|---|---|
| `expert-voice-builder` | 인터뷰로 내 말투·타겟·전문 분야를 정리한 기준 문서(`expert-voice.md`)를 만듭니다 |
| `channel-copywriter` | 그 기준 문서를 바탕으로 Threads·LinkedIn 게시글을 내 목소리로 씁니다 |

기준 문서를 한 번 만들어두면 이후 콘텐츠가 모두 같은 목소리로 나옵니다.

---

## 1. 내려받기

이 페이지 오른쪽 위 **`Code`** → **`Download ZIP`** 을 누르고 압축을 풉니다.

## 2. 내 도구로 이 폴더 열기

세 도구 모두 쓸 수 있게 준비되어 있습니다. 쓰시는 도구로 압축 푼 폴더를 열면 됩니다.

| 도구 | 여는 방법 |
|---|---|
| **Claude Code** | 터미널에서 해당 폴더로 이동 후 `claude` |
| **Antigravity** | 프로그램에서 이 폴더를 프로젝트로 열기 |
| **Codex CLI** | 터미널에서 해당 폴더로 이동 후 `codex` |

## 3. 브랜드보이스 만들기

채팅창에 스킬 이름을 붙여 요청합니다.

```
/expert-voice-builder 브랜드보이스를 만들려고 해. 인터뷰를 진행해줘.
```

전문 분야, 주로 돕는 분, 자주 받는 질문, 평소 말투, 실제 겪은 사례를 하나씩 물어봅니다. 아는 만큼만 답해도 문서는 완성됩니다.

끝나면 폴더에 `expert-voice.md`가 생깁니다.

## 4. 채널 카피 만들기

```
/channel-copywriter 이 주제로 Threads 카피 써줘: (주제 또는 원고)
```

방금 만든 `expert-voice.md`를 찾아 읽고, 그 말투와 CTA에 맞춰 카피를 씁니다.

| 요청 | 생성되는 파일 |
|---|---|
| Threads 카피 | `threads-copy.md` — 3버전, 각 500자 이내 |
| LinkedIn 포스트 | `linkedin-copy.md` — 1편, 1,300~1,900자 |
| 채널별 카피 | 위 두 파일 |

## 강의와의 관계

이 키트는 브랜드보이스(D1)와 채널 카피(D2)를 다룹니다. 콘텐츠 캘린더(D3)·이미지(D4)·실제 발행(D5)은 강의 프롬프트북과 Buffer로 진행합니다.

## 잘 안 될 때

| 증상 | 조치 |
|---|---|
| 스킬을 못 찾음 | 압축 푼 폴더 자체를 열었는지 확인 (하위 폴더를 열면 인식하지 못합니다) |
| 방금 넣었는데 안 뜸 | 도구를 껐다 켜기 — 스킬은 시작할 때 읽어들입니다 |
| 자동으로 반응하지 않음 | `/expert-voice-builder 스킬로 인터뷰해줘` 처럼 스킬명을 직접 불러 요청 |

## 이 키트에 들어있는 것

```
snsmkt-kit/
├── README.md          ← 지금 보고 계신 사용 안내
├── CLAUDE.md          ← AI 도구가 읽는 작업 지침
├── AGENTS.md          ← 같은 지침의 Codex CLI용 사본
├── .claude/skills/    ← Claude Code용
├── .agent/skills/     ← Antigravity용
└── .codex/skills/     ← Codex CLI용
```

세 폴더에 같은 스킬이 들어 있습니다. 도구마다 스킬을 찾는 위치가 달라 세 벌을 넣어두었습니다.

`CLAUDE.md`와 `AGENTS.md`는 AI 도구가 이 키트를 다룰 때 참고하는 파일입니다. 사용하실 때 열어보거나 수정하실 필요는 없습니다.
