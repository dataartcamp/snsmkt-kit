# 전문가 보이스 빌더

`expert-voice.md`는 전문 분야·돕는 대상·말투·CTA·금지어·실제 사례를 담은 기준 문서다. 한 번
만들어두면 이후 콘텐츠가 여기서 파생되어 목소리가 흔들리지 않는다.

## 인터뷰

다음 7가지를 채운다:

1. 전문 분야
2. 주로 돕는 대상 — 고객·청중
3. 자주 받는 질문·고민 상담
4. 나만의 관점·철학 — 남들과 다른 부분
5. 평소 말투 — 딱딱함·친근함·유머 등 + 쓰기 싫은 표현·금지어
6. 실제로 겪은 구체적 사례 1~2개 — 숫자·디테일 포함
7. 사람들이 해주길 바라는 행동(CTA) — 상담 신청·자료 받기·댓글 등 실제로 운영 중인 것

규칙:
- **한 번에 하나씩 묻는다.** 7개를 한꺼번에 나열해 양식처럼 제출받지 않는다.
- 사용자가 이미 준 정보는 건너뛰고 **빈 항목만** 묻는다.
- 답이 막연하면 한 단계만 더 파고들고 멈춘다. 완벽한 입력이 아니라 완성된 문서가 목적이다.

## 출력 — `expert-voice.md`

아래 제목을 **글자 그대로** 쓴다. `channel-copywriter`가 "CTA 섹션"·"전문 분야"·"금지어"를
이름으로 찾아 쓰므로, 제목을 바꾸면 카피 쪽이 조용히 깨진다.

```markdown
# 내 전문가 보이스 — expert-voice.md

## 나는 누구인가
한 문장 (무엇을 하는 사람 + 남과 다른 한 가지)

## 전문 분야
분야를 나타내는 키워드 3~5개 (쉼표로 구분)

## 내가 돕는 사람
누구를 돕는지 + 그들이 아직 못 가진, 원하는 것

## 내 제안·행동유도(CTA)
3개 (각각 한 줄 행동 지시)

## 내 말투 (보이스)
- 유머↔진지 / 대담↔겸손 / 캐주얼↔격식 / 짧게↔이야기체 (각 한 줄)
- 되도록 피하고 싶은 표현·금지어

## 내가 자주 쓰는 말
실제로 내가 쓸 법한 표현 5개

## 내 진짜 이야기 (AI 티를 없애는 연료)
성공·실패·의외 사례 각 1개 (구체적으로)

## 내가 내세울 수 있는 것 (증거)
경력·숫자·성과

## 계속 다룰 주제 (콘텐츠 기둥)
3~5개
```

## 작성 규칙

| 상황 | 규칙 |
|---|---|
| **항상** | 전문용어를 최소화하고, 사용자가 실제로 쓴 표현·사례를 살려 그 사람답게 쓴다 |
| | 이 문서 하나만 읽고도 AI가 그 사람처럼 쓸 수 있을 만큼 구체적으로 채운다 |
| | 사용자가 말하지 않은 경력·숫자·성과를 지어내지 않는다 |
| **답을 못 받은 항목** | 본문 섹션은 비워두고, 무엇이 비었는지는 "보완할 것"에만 적는다 |
| | 본문에 `※`·`(아직 없음)` 같은 안내 문구를 섞지 않는다 — 카피 생성 시 그대로 새어나간다 |
| | "증거" 섹션은 특히 사실만 — 없으면 비우고 "보완할 것"으로 넘긴다 |
| **다 채워진 문서** | "보완할 것" 섹션은 통째로 지운다 |
